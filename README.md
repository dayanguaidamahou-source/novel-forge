# 墨改 · 小说工坊（Novel Forge）

一个 SillyTavern 客户端扩展：把整本 txt 小说导进来，按章改写 / 扩写 / 续写，跟原版逐句对照，改完导出。

- 只在你自己的设备上跑，除了你自己填的 API 地址，不连任何第三方。
- 零依赖、零构建：三个文件拷进去就能用（`manifest.json`、`index.js`、`style.css`）。
- 电脑版 SillyTavern 和安卓壳（TauriTavern 之类）通用。

---

## 一、安装

### 方式 A：从 GitHub 地址安装（最省事）

前提：仓库是 **public**。

1. 打开 SillyTavern，点顶部的「扩展」（Extensions）图标。
2. 在 **Install Extension** 的输入框里粘贴仓库地址，例如：

   ```
   https://github.com/你的用户名/novel-forge
   ```

3. 点 **Install**，等它克隆完，刷新页面（Ctrl+F5）。
4. 右下角出现蓝色圆球，点开即可。

更新插件也是同一个输入框，再点一次 Install 会拉最新版。

### 方式 B：手动放文件

#### 电脑版 SillyTavern

1. 关掉 SillyTavern（或装完再刷新页面）。
2. 打开 SillyTavern 的安装目录，找到：

   ```
   SillyTavern/data/default-user/extensions/
   ```

   > 如果你用的是别人打包的整合包，`data` 目录也可能叫 `SillyTavern/data`、`SillyTavern-release/data`，
   > 里面一般已经有一个 `default-user` 文件夹，跟着它走就行。

3. 在这个 `extensions` 文件夹里新建一个文件夹，名字叫 `novel-forge`。
4. 把本目录下的三个文件拷进去，最终结构是：

   ```
   data/default-user/extensions/novel-forge/
   ├── manifest.json
   ├── index.js
   └── style.css
   ```

5. 启动（或刷新）SillyTavern，右下角出现一个蓝色圆形按钮，点它打开面板。

#### 安卓（TauriTavern 等手机壳）

手机壳本质上是把 SillyTavern 跑在手机里，数据目录在 App 的私有空间：

1. 用手机自带的「文件管理」或 MT 管理器，进入 App 的数据目录，一般长这样：

   ```
   Android/data/<壳的包名>/files/SillyTavern/data/default-user/extensions/
   ```

   有些壳把它放在：

   ```
   /storage/emulated/0/SillyTavern/data/default-user/extensions/
   ```

   不确定就搜 `default-user` 这个文件夹名。

2. 在里面新建 `novel-forge` 文件夹，把三个文件拷进去（同上）。
3. 回到 App，下拉刷新或重启，右下角出现蓝色按钮。

#### 如果上面两个位置都不对

任何 SillyTavern 都认另一条老路径，效果一样：

```
<SillyTavern 根目录>/public/scripts/extensions/third-party/novel-forge/
```

三件套放这里也能加载。**两个位置只放一份**，不要同时放，否则会出现两个悬浮球。

## 二、第一次使用：先填 API

点右下角按钮 → 顶部「设置」：

| 项目 | 说明 |
| --- | --- |
| 接口地址 | OpenAI 兼容地址，例如 `https://api.deepseek.com/v1`、`https://api.openai.com/v1`、你本地反代的地址 |
| API Key | 对应的密钥，存在本机 localStorage，不上传 |
| 模型 | 生成用模型名，例如 `deepseek-chat` |
| 概括专用模型 | 可留空；填了就用便宜的模型跑章节概括，省钱 |
| 温度 | 建议 0.8–1.0，太高容易跑偏 |
| max_tokens | 单次回复上限，长章节建议 8192 以上 |

填完点「测试连接」，能回一句话就通了。也可以点「拉取模型列表」直接从接口读模型名。

### 关于接口地址的小提示

插件会自动补 `/chat/completions`，也会自动试带不带 `/v1`。
所以下面两种写法都能用：

- `https://api.deepseek.com/v1`
- `https://api.deepseek.com`

## 三、使用流程

### 1. 导入

「写作」页左上「导入 txt」，选文件；或者「粘贴文本」直接贴整本。

切章规则内置了常见的六种写法（`第X章`、`第X回/节/话`、`第X卷`、`Chapter N`、`序章/楔子/尾声`、`（一）`、`1、`）。
切得不准就在「设置 → 上下文与切章 → 自定义切章正则」写一条自己的，比如 `^第\s*\d+\s*章`。

导入后可以在「书架」里切换多本书，书都存在浏览器的 IndexedDB 里。

### 2. 选章、写要求、生成

1. 左边点一章。
2. 上面选 **改写 / 扩写 / 续写**。
3. 在指令框写清楚要什么，比如：
   - 改写：「把这段打斗写得更血腥一点，多写环境和痛感，删掉心理独白」
   - 扩写：「把两人重逢那段展开到 3000 字，加一段回忆」
   - 续写：「接着写主角进城，遇到旧识，留一个反转」
4. 点「生成」。生成过程中按钮会变成「停止生成」，卡住或写歪了可以随时中断——已经写出来的部分会保留，可以直接接着改。

生成前可以点「看上下文」，它会把**真正要发给 AI 的每一段**摊开给你看——文风、人物、摘要、原文、指令各占多少字，一目了然。

### 3. 对比、手改、保存

- 右边是「改后」，默认「对比」模式：新增的句子绿底，删掉的句子红底带删除线。
- 觉得哪里不对，切到「编辑」直接改字。
- 「保存为新版本」：旧内容进历史，新内容成为本章正文；摘要会被标记成「已过期」（提醒你重新概括，不会自动跑）。
- 「丢弃」：这一次的生成结果不要了。
- 「换一版」：同样的要求再生成一次。

续写模式下保存会**插入新的一章**，不会覆盖原来那章。

每章右上角的「⋯」里可以：重命名、重新概括、看历史版本并回滚、删除本章。

### 4. 导出

右上角下载图标 → 导出整本 txt（一章接一章，带章节名，UTF-8 带 BOM，Windows 记事本打开不乱码）。

「设置 → 导出工程 json」会导出带摘要、文风卡、历史版本的完整工程文件，用于换设备或备份。

## 四、记忆库（这是能写长篇的关键）

AI 一次看不完几十万字。插件的做法是给书建三层档案，每次只发「档案 + 最近原文」：

### ① 章节档案（档案页 → 章节档案）

每章压成约 200 字（字数可调），包含：

- 情节概要
- 关键事件 3–5 条
- 登场人物：名字｜当前状态｜此刻在做什么
- 伏笔

**先跑概括再写效果最好**：点「只补缺失」把没概括的补上，或「批量概括全部」。批量过程中再点一次按钮可以停。摘要条目上点「编辑」可以手动改——AI 概括漏了人，你自己补一句就行。

### ② 文风卡（档案页 → 文风档案）

点「AI 提炼」会抽全书若干段正文，总结出人称视角、句式节奏、用词习惯、对话写法、要避免什么。续写时会把这段塞进提示词，避免「换了个人写」。不满意直接改，点保存。

### ③ 分卷摘要（档案页 → 分卷摘要）

上下文超过预算时，最早的若干章会被合并成一条 300–450 字的主线概述，原章档案仍然保留。
「压缩最早 10 章」可以手动压；每次压几章由「设置 → 超预算时每次压缩几章」决定（默认 10）。

### 三层怎么用

| 场景 | 发出去的内容 |
| --- | --- |
| 改写 / 扩写 | 文风卡 + 人物档案 + 上一章摘要 + 下一章摘要 + 本章原文 + 你的指令 |
| 续写 | 文风卡 + 分卷摘要 + 近期章摘要 + 最近 2 章原文 + 本章结尾 1200 字 + 指令 + 大纲 |

总预算在「设置 → 上下文总预算」里，默认 50000 字。超了插件自己会裁：先丢最老的摘要，再切原文，最后截分卷摘要。

## 五、探讨页（和 AI 聊剧情）

「探讨」页是个纯聊天窗口，带上了文风卡、人物状态、近期剧情摘要（勾「带上本章原文」还会带本章节选）。

适合问：「主角该不该在这里暴露身份？」「给三个结局走向，说清代价」「这一章节奏是不是太快了」。

AI 的每条回复下面有三个按钮：

- **当作指令**：把这段话填进写作页的指令框，直接拿去生成。
- **存为大纲**：存成续写大纲，之后续写会自动带上（`{{大纲}}`）。
- **复制**。

## 六、预设提示词与破限

「设置 → 提示词」有两栏：**创作预设**（决定怎么写）和**破限提示词**（决定 AI 放不放得开）。

- 预设可以新增、改名、删除；删到只剩一套时会拦住。
- 每套预设下面有「改写用它 / 续写用它」两个按钮，指定哪种模式默认用这套。默认自带「改写/扩写」「续写」两套。
- 破限提示词可以选「追加在最后」或「放在最前」，也可以整体关掉。

### 预设里能用的变量

点变量标签会插到光标处：

| 变量 | 内容 |
| --- | --- |
| `{{文风卡}}` | 全书文风档案 |
| `{{人物}}` | 人物当前状态表（取最近出场） |
| `{{最近摘要}}` | 最近若干章摘要 |
| `{{分卷摘要}}` | 早期章节压缩后的主线 |
| `{{最近原文}}` | 最近 N 章正文（续写） |
| `{{本章结尾}}` | 本章末尾一截 |
| `{{原文}}` | 当前章全文（改写） |
| `{{上一章摘要}}` / `{{下一章摘要}}` | 前后章剧情 |
| `{{指令}}` | 指令框里的要求 |
| `{{大纲}}` | 探讨室存下的大纲 |
| `{{目标字数}}` | 本次目标字数 |
| `{{书名}}` / `{{章节名}}` | 书名、章名 |

改预设时注意：**输出要求那几条别删**。尤其是「只输出正文、不要解释、不要 Markdown」——删了 AI 就会开始跟你聊天，输出会带一堆「好的，以下是修改后的内容」。

## 七、常见问题

**右下角没有按钮？**
先确认三个文件在同一个文件夹里，且 `manifest.json` 里 `js` 写的是 `index.js`。然后强制刷新（Ctrl+F5）或重启 App。仍不行就看浏览器控制台有没有 `[novel-forge]` 开头的报错。

**点生成报 401 / 403？**
Key 错了或没权限。报 404 一般是接口地址少了 `/v1` 或多了路径，插件会自动重试一次，两次都失败才报错。

**报超时？**
`max_tokens` 太大或网络慢。设置里没有直接暴露超时，默认 240 秒；章节特别长时可以先降目标字数。

**切章切错了？**
设置里写自定义正则；或者导入前把章节标题统一成 `第X章 标题` 这种格式。

**改写完，摘要变「已过期」了怎么办？**
这是故意的：正文变了，旧摘要就不准了。到档案页点那一章的「重算」就行，不会自动花钱。

**数据存在哪？会丢吗？**
书存在浏览器的 IndexedDB（按域名隔离），设置存在 localStorage。清浏览器数据、换 App、换域名都会丢，所以**重要进度记得定期「导出工程 json」**。导出的 txt 是最终成品，另存一份最稳。

**手机上排版挤？**
面板在窄屏下自动变成全屏单列，章节列表在上、编辑区在下。悬浮球可以拖着换边。

**会不会和我别的插件打架？**
所有类名都带 `nf-` 前缀，悬浮球和面板的 `z-index` 在 2000000 以上，样式只作用在 `#nf-root` 内部。

## 八、文件说明

| 文件 | 作用 |
| --- | --- |
| `manifest.json` | 扩展声明，SillyTavern 靠它发现插件 |
| `index.js` | 全部逻辑：切章、上下文拼装、API 直连、diff、界面 |
| `style.css` | 全部样式，`nf-` 前缀，主色走 `--nf-accent` |

想换主色：CSS 里 `#nf-root` 的 `--nf-accent` 改一个色值即可，其余（浅底、描边、阴影）会自动跟着变。
